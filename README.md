
# Day 16 - Spark Joins and Aggregation

## Objective
Practice Spark DataFrame joins, grouping, aggregation, and filtering using Scala.

## Datasets
- 15 employee records
- 5 department records

## Concepts Covered
1. Inner Join
2. Left Join
3. groupBy
4. count, avg, sum, max, min
5. round
6. filter

## Technologies
- Scala 2.12.18
- Apache Spark 3.5.9
- sbt 2.0.8
- Java 17

## Run the Project

```bash
export JAVA_TOOL_OPTIONS="--add-opens=java.base/sun.nio.ch=ALL-UNNAMED"
sbt run
```
